# DisasterSafe React

Converted from the supplied HTML/CSS/JavaScript project into a React + Vite application.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
1. Extract this ZIP.
2. Open the `disastersafe-react` folder in VS Code.
3. Open the terminal in that folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite (usually http://localhost:5173).

## Demo login
- User: `user@demo.com` / `123456`
- Admin: `admin@demo.com` / `admin123`

## Routes
- `/` - Home page
- `/login` - Login
- `/signup` - Sign up
- `/dashboard` - Citizen dashboard
- `/admin` - Admin dashboard

## Notes
This remains an educational frontend demo. Accounts, sessions and incident reports are stored in browser LocalStorage. It does not provide production-grade authentication, a backend database, real emergency alerts, verified shelter data, or live location/weather services. Do not rely on it for real emergency response.
